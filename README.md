### Sobre mim

**🧑‍💻 Dev de software | Mobile & Backend**

Curto entender o problema como um todo: da tela do app até a API, o banco de dados e a infra que sustenta tudo isso rodando.

No mobile, crio apps multiplataforma com Flutter, sempre de olho em arquitetura, organização de código, qualidade e experiência de quem usa.

No backend, hoje trabalho com .NET, C#, Entity Framework e SQL Server, construindo APIs e soluções integradas ao ecossistema dos apps.

Também já rodei bastante com Firebase, CI/CD, banco de dados e um bocado de outras ferramentas do ciclo de desenvolvimento.

- 💻 Codando apps com amor e um pouco de ódio desde 2019.
